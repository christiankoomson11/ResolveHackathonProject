# RESOLVE – Student Case Management System

## Overview

RESOLVE is a student case management system developed as part of a collaborative software engineering project. The platform was designed to improve how universities manage, track, and organise student support cases through a centralised and user-friendly system.

The project focuses on streamlining communication between departments, improving case visibility, and supporting efficient management of sensitive student concerns.

---

## Features

* Secure user authentication and login system
* Interactive dashboard with case analytics
* Case creation and tracking functionality
* Case status monitoring and management
* Search and filtering features
* Responsive and user-friendly interface
* Centralised management of student support cases

---

## Technologies Used

* Next.Js
* HTML
* CSS
* JavaScript
* SQL / Database Design
* Git & GitHub
* Agile Development Methodologies

---

## Project Structure

The project was developed using a collaborative Agile workflow with task management and sprint planning through Trello. Team members contributed across frontend development, system planning, testing, documentation, and database design.
